# 🐾 Pokémon Sprite Fetcher

Jednostavna web aplikacija koja omogućava pretraživanje Pokémona po imenu i prikazuje njihovu zvaničnu sličicu (sprite) uživo.

## 🚀 Tehnologije
* **HTML5** — Struktura stranice
* **CSS3** — Osnovno stilizovanje
* **JavaScript (ES6+)** — Asinhroni rad sa podacima (`async/await`, `fetch` API)
* **[PokéAPI](https://pokeapi.co/api/v2/pokemon)** — REST API za preuzimanje podataka o Pokémonima
